# Lege čistoće OS — demo

Statična, responzivna demo landing stranica za usluge čišćenja u Osijeku i okolici.

## Pokretanje

Otvorite `index.html` u pregledniku ili objavite projekt na Vercelu kao statički projekt.

> Kontaktni podaci, fotografije, recenzije i obrazac trenutno su demo sadržaj. Obrazac ne šalje podatke na server.
